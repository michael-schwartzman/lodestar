# Privacy

_In effect from 21 November 2026._

Lodestar is a game for one player. This page says what it does with information about the person playing it:
in the iPhone app, and in a browser.

## Lodestar: Operation Hammerfall, the iPhone app

**The app collects nothing.** It has no accounts, no advertising, no analytics and no tracking, and it does not
use the network at all: the whole game is inside the app, and nothing a player does in it is sent anywhere.

- **Scores and the callsign** a player types after a mission are kept on the phone and nowhere else. Deleting
  the app deletes them.
- **Settings** (sound, controls, how the game looks) are kept on the phone in the same way.
- **Haptics**: the app makes the phone tap and buzz. That uses no information about anybody.
- **It asks for no permission**: not the camera, the microphone, location, contacts, photos or notifications.

Because nothing is collected, there is nothing to share, to sell, or to ask to have deleted.

## The game in a browser

The game in this repository is the same game as a web page, which anybody may host.

- **By itself it keeps the same things in the same way**: settings, scores and a callsign, in the browser's own
  storage on the player's device. Clearing the site's data in the browser removes them.
- **A shared scoreboard is optional.** Whoever hosts a copy of the game may give it a scoreboard of their own
  (the README says how). Where that has been done, nothing is posted until a player has typed a callsign and
  pressed POST. From then on that copy posts, under that callsign, each mission the player wins and each loss
  that beats their own best: the callsign, the score, and a few facts of the mission (the difficulty, how it
  ended, how long it took, how many machines were shut down and alarms raised, and whether it was played on a
  phone or at a desk). The other players of that copy can see them. Clearing the site's data in the browser
  forgets the callsign, and nothing more is posted until one is typed again. What that host keeps, and for how
  long, is that host's to answer for.
- Like any web page, a hosted copy is fetched from a server, and a server sees the network address a request
  comes from. That is the host's, too.

## Children

The game is not made for children under 13, and it collects nothing from anybody of any age.
